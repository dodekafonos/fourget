
# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

## [0.1.0] - 01/02/2026

### Adicionado
- Estrutura inicial do projeto com Turborepo
- Frontend React + TypeScript + Vite
- Tabuleiro 6x6 renderizado com Konva
- Sistema de cartas com emojis (18 pares)
- Lógica completa de flip com timer (2s)
- Detecção automática de pares
- Sistema de pontuação (1 ponto/par)
- Alternância inteligente de turnos
- Store global com Zustand
- Componente de status do jogo
- README completo com documentação

### Corrigido
- Geração aleatória de emojis sem repetição excessiva
- Sincronização de estado entre componentes
- Timing do flip de cartas

### Previsão das Próximas Versões
- [0.2.0] Detecção de 4 em linha e fim de jogo
- [0.3.0] IA básica para singleplayer
- [0.4.0] Sistema multiplayer
